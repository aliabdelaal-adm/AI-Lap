# Dubai Studio AI Lab

أساس مفتوح وقابل للتطوير لإنشاء إعلانات مرئية وصوتية. الحالة الحالية هي **نموذج أولي للخدمة فقط**: يوفّر واجهة عربية/إنجليزية وواجهة API آمنة لاستقبال مدخلات الإعلان، لكنه لا يشغّل نموذج فيديو بعد. لا يتم إنشاء فيديو تجريبي أو ادعاء نجاح التوليد دون محرك فعلي.

## الحالة الحالية

| المجال | الحالة |
|---|---|
| رفع صورة شخصية وصورة منتج اختيارية وتسجيل صوتي ووصف المشهد | مبرمج؛ يتحقق من توقيع الملف والحجم |
| تسجيل المهام وحالات الانتظار/التشغيل/الفشل/الإلغاء | مبرمج؛ SQLite وطابور داخل العملية |
| عزل الملفات بحسب هوية رمز API | مبرمج؛ رمز مستقل لكل مستخدم |
| محرك InfiniteTalk | مخطط؛ لم يُدمج كود upstream الموجود على GitHub |
| توليد فيديو | لم يُختبر على GPU؛ هذه البيئة بلا GPU ولا أوزان |
| واجهة عربية/إنجليزية | مبرمجة؛ صفحة ويب خفيفة |
| فهرس النماذج | بحث أولي؛ تفاصيل الترخيص/الموارد غير المحسومة معلّمة |

هذا ليس جاهزًا للإنتاج التجاري: طابور SQLite محلي، ولا توجد بعد قاعدة مستخدمين/مشاريع كاملة، فوترة، تخزين كائنات، worker دائم، أو مراجعة قانونية شاملة.

## التشغيل محليًا

يتطلب Python 3.10 أو أحدث. لا تُنزّل أوزانًا أو مستودعات نماذج تلقائيًا.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
export STUDIO_API_TOKENS='{"local":"ضع-هنا-رمزا-عشوائيا-بطول-32-محرفا-على-الأقل"}'
uvicorn studio_ai_lab.app:app --host 127.0.0.1 --port 8000
```

أنشئ الرمز في الطرفية بدل وضعه في Git أو السجلات، مثلًا:

```bash
python -c 'import secrets; print(secrets.token_urlsafe(32))'
```

افتح `http://127.0.0.1:8000/`، ثم أدخل الرمز في الواجهة. توثيق API في `/docs`. لا تعرض الخدمة للإنترنت دون TLS وتخزين أسرار مُدار وحدود وصول على مستوى الشبكة.

تُحفظ البيانات افتراضيًا في `./data` ويمكن تغييرها عبر `STUDIO_DATA_DIR`. الملفات تُخزّن بأسماء مولّدة وصلاحيات خاصة بالمستخدم على أنظمة POSIX؛ لا تضع المجلد على مساحة عامة. تُقيّد الصورة بـ20 MiB والصوت بـ100 MiB لكل ملف. التحقق الحالي من تواقيع الملفات أولي ولا يحل محل فك ترميز الوسائط أو فحصها قبل تمريرها إلى محرك.

## API مختصر

- `GET /health` — فحص الخدمة وحالة توفر محرك الفيديو.
- `GET /v1/system/resources` — موارد CUDA المتاحة (يتطلب رمز Bearer).
- `GET /v1/models` — سجل النماذج ودرجة التحقق.
- `POST /v1/jobs` — `multipart/form-data`: `image` و`audio` مطلوبان؛ `product_image` اختياري؛ `scene` مطلوب؛ `seed` اختياري.
- `GET /v1/jobs` و`GET /v1/jobs/{id}` — مهام المستخدم الحالي فقط.
- `POST /v1/jobs/{id}/cancel` — إلغاء مهمة لم تنتهِ بعد.
- `GET /v1/jobs/{id}/output` — تنزيل الفيديو عند نجاح محرك موصول فقط.

تستخدم كل طلبات `/v1` ترويسة التفويض `Authorization` مع رمز من `STUDIO_API_TOKENS`، وهو كائن JSON يربط معرف المستخدم برمز سري لا يقل عن 32 محرفًا. عند عدم ضبط الرموز ترفض الخدمة الطلبات المحمية. في النسخة الحالية تنتهي مهمة الإنشاء بفشل صريح `No video-generation adapter is configured`، ولا تُعاد المحاولة تلقائيًا حتى لا تتكرر تكلفة محتملة.

## ما لم يُنجز بعد

لم يُفهرس 30 نموذجًا مع تفاصيل موثقة؛ السجل الحالي قصير عمدًا ولا يخترع تفاصيل. لم يتم استنساخ/تثبيت مصدر InfiniteTalk، تنزيل أوزان، تشغيل GPU، تقييم العربية أو اللهجة الإماراتية، تدريب/LoRA، أو مقارنة تجارية. يلزم إنجاز ذلك والتحقق من تراخيص كل مكوّن على حدة قبل أي إطلاق أو ادعاء أداء.
